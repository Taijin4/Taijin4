## 🚀 A propos de moi

Étudiant en informatique passionné, j'ai déjà accumulé de solides expériences en développement web full-stack, mais je ne me définis pas uniquement comme un "web dev". Chaque projet personnel est pour moi une occasion d'explorer de nouveaux horizons : intelligence artificielle, application mobile, automatisation, jeu-vidéo, ...

- 🎓 **Étudiant en** : BUT Informatique à l’IUT Robert Schuman
- 💼 **Expériences professionnelles** :
  - Stage de 2,5 mois en ESN, développement d’ERP sur mesure
  - Alternance Full-Stack à l’IRCAD, institut de recherche chirurgicale
  - Co-fondateur d’une agence de digitalisation web (landing pages & sites vitrines pour TPE/PME)
  - Missions freelance variées : sites vitrines, maintenance et optimisations

🔭 **Projets personnels** :
- Sites web innovants
- Applis mobiles (suivi sportif, conversion de playlists entre plateformes de streaming)
- Bots d’automatisation et prototypes tech

🌱 **Ce qui me motive** : apprendre au-delà du web dev, explorer IA, IoT, VR/AR, blockchain, DevOps...

🌍 **Localisation** : Strasbourg, France
